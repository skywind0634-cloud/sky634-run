# 血統分析の設計と知見

このシステムは「血統の事前知識」と「実績データの集計」を組み合わせ、各馬の**条件適性**を数値化して勝率を出す。
事前知識（`data/knowledge/`）はデータの少ない条件での出発点であり、実績データが増えるほど自動的にデータ側の比重が大きくなる（経験ベイズ縮約）。

---

## 1. 評価の全体像

| 区分 | 内容 | 実装 |
|---|---|---|
| A. 血統事前適性 | 父(65%)＋母父(35%)の12軸適性ベクトル × レース条件の要求ベクトル | `model.race_demand`, `knowledge.sire_apt` |
| B. ニックス・牝系・クロス | 父×母父(系統)の相性、名門牝系、5代内インブリード | `knowledge.nick_prior / detect_family / detect_crosses` |
| C. 実績集計 | 種牡馬/系統/母父/ニックス/兄弟の条件別複勝率、道悪、ペース、騎手・調教師・コンビ、枠順 | `analysis.build_stats` |
| D. 近走フォーム | 直近5走の着順率をクラス補正・同条件重み付け | `model.form_score` |
| E. 展開・脚質 | 通過順から脚質とテン指数 → 全馬から展開(ペース)予想 → ペース×脚質×コース脚質バイアス、単騎逃げ、上がり性能、ペース型別の自身の成績 | `racing.py` |
| F. 距離 | 好走距離の中心、今回距離±200mの成績、距離延長/短縮、父のピンポイント距離実績、系統別の延長/短縮成績 | `racing.build_profile`, `analysis` |
| H. その他の要因 | ローテ・斤量・馬体重・昇級/降級・乗り替わり・季節×性別/年齢・コース実績・左右回り・タイム指数・着差・インブリード実績・新馬・頭数・回収率 | `factors.py` |
| G. 市場 | 単勝オッズがあれば市場確率と対数線形ブレンド | `model.evaluate_race` |

勝率 = softmax(スコア / T)、3着内率は Harville モデルのモンテカルロ（3万回）で算出。T と市場ブレンド比は `backtest --save` で過去データから最適化する。

### 適性の12軸
芝 / ダート / 短距離(〜1400) / マイル(〜1700) / 中距離(〜2200) / 長距離(2300〜) / 道悪 / 瞬発力 / 持続力 / パワー / 早熟性 / 成長力

レース条件の要求ベクトルは「馬場種別 1.2」「距離帯 1.0」「道悪時 0.8」＋「コース特性(demand)×0.6」＋年齢補正（2歳=早熟、5歳以上=成長力）。
芝レースでのダート血統・短距離戦での長距離血統など、**反対側の適性が強すぎる血統は減点**する。

### 実績集計の階層縮約
例: 父キズナの東京芝1800mの評価は
`系統(ディープ系)の芝全体 → 系統の芝中距離 → キズナの芝中距離 → キズナの東京芝中距離`
の順に、各段で「(3着内数 + 20×上位段の率) / (出走数 + 20)」と縮約。出走数の少ない条件で偶然の好成績を過大評価しない。

## 2. 父系（サイアーライン）の要点

### サンデーサイレンス系
- **ディープインパクト系**（キズナ・リアルスティール・サトノダイヤモンド・コントレイル・シルバーステート・ミッキーアイル）
  軽い芝の瞬発力戦で最強。東京・京都外回り・阪神外回り・新潟外回り。重馬場・急坂の消耗戦は割引。
  - キズナは母父Storm Catの影響でパワー・持続寄り、芝ダ兼用・道悪可。
  - リアルスティールはフォーエバーヤングを出しダート適性が明確。
  - ミッキーアイルは短距離特化型。
- **ステイゴールド系**（オルフェーヴル・ゴールドシップ・インディチャンプ）
  スタミナ・持続力・道悪・小回り急坂。中山/阪神内回り/洋芝/長距離の消耗戦。気性ムラ→人気薄の一発。
- **ハーツクライ系**（スワーヴリチャード・ジャスタウェイ）
  東京の長い直線で長く良い脚。晩成。スワーヴリチャードは牝馬の大物（レガレイラ）と菊花賞馬（アーバンシック）。
- **ブラックタイド系**（キタサンブラック）: 先行持続力と古馬の成長力。イクイノックス・クロワデュノール。
- **ダイワメジャー系**（アドマイヤマーズ）: 先行力のマイラー、早熟傾向。
- **ゴールドアリュール系**: ダート中距離の王道。

### キングカメハメハ系（キングマンボ系）
芝ダ兼用、持続力型、母系の特徴を引き出す。SS系牝馬との配合が王道。
- **ロードカナロア**: スプリント〜マイルが本線、SS系母父で中距離G1馬（アーモンドアイ・サートゥルナーリア）。
- **ドゥラメンテ**: 持続力とパワーで中長距離G1量産（タイトルホルダー・リバティアイランド）。欧州スタミナ母父と好相性。
- **ルーラーシップ**: 長く脚を使う持続力型。出遅れ癖に注意。
- **リオンディーズ**（テーオーロイヤル）・**サートゥルナーリア**（シーザリオ牝系）。

### ロベルト系
パワーと持続力。中山・阪神内回り・洋芝・道悪・冬の荒れ馬場、上がりの掛かる消耗戦で浮上。
- **エピファネイア**: 3歳春の爆発力、牝馬の大物。SS系牝馬との配合でサンデーのクロスが生じ、瞬発力が強化。
- **モーリス**: マイル〜中距離のパワー型、古馬で成長。

### 米国ダート系
- **ヘネシー系**（ヘニーヒューズ・アジアエクスプレス）: ダート短距離のスピード。湿ったダートで時計が速い時に一段と強い。
  2026年スプリンターズSはピューロマジック（父アジアエクスプレス×母父ディープインパクト）が9番人気で優勝 — ダート血統×SSの芝短距離適性。
- **エーピーインディ系**（シニスターミニスター・パイロ・マジェスティックウォリアー）: 乾いた力の要るダート中距離。
- **デピュティミニスター系**（マインドユアビスケッツ・クロフネ）: ダート中距離〜マイル、クロフネは母父として芝ダのスピード。

### 欧州系
- **デインヒル系**（ハービンジャー）: 洋芝・道悪・時計の掛かる芝の中距離。高速決着の瞬発力戦は苦手。
- **ガリレオ系**（ポエティックフレア・Frankel産駒）: 欧州のマイル〜中距離の持続力とパワー。
- **サドラーズウェルズ系**: 父として日本の高速馬場では瞬発力不足になりやすいが、母父に入ると底力（タイトルホルダー・ソールオリエンス）。

| ディープ系 × Storm Cat | +2 | キズナ、リアルスティール、ラヴズオンリーユー |
| ロードカナロア × SS系母父 | +1.5 | アーモンドアイ、サートゥルナーリア |
| エピファネイア × SS系母父 | +1.5 | エフフォーリア |
| キズナ × シンボリクリスエス系 | +1.5 | ソングライン、アカイイト |

## 5. 牝系
名門牝系（ダイナカール、シーザリオ、スカーレットインク、ビワハイジ、ベガ、ウインドインハーヘア、パシフィカス、ハルーワスウィート、ミエスク 等）を
母系5代以内に持つ馬にボーナス。加えて**同じ母の産駒（兄弟姉妹）の実績**を集計して反映する。

## 6. コース・馬場・ラップ
- **コース要求**（`courses.json`）: 東京/京都外/新潟外=瞬発力、中山/阪神内/福島/札幌/函館=パワー・持続力、小倉=持続力。
- **馬場**: 稍重〜不良では『道悪』軸を要求に追加し、種牡馬・系統別の道悪実績を反映。ダートの湿った馬場ではスピード型（ヘネシー系等）。
- **ラップ分類**（`scraper.netkeiba.classify_pace`）: 瞬発（後半3Fが1秒以上速く終いで加速）/ 持続（ラスト4Fが一定）/ 消耗（前傾）/ 平均。
  系統・種牡馬別のペース別成績を集計し、カードに `expected_pace` を入れると反映される。

## 7. 距離の分析
| 観点 | 中身 |
|---|---|
| 血統の距離適性 | 父65%＋母父35%の「短距離/マイル/中距離/長距離」軸。反対側の距離帯が強い血統は減点（長距離血統の1200m戦など） |
| 馬自身の距離適性 | 同じ芝/ダでの好走距離（着順率0.6以上）の加重中心＝「ベスト距離」。今回±200mの成績を全体平均と比較（走数で信頼度調整）。未経験距離はベスト距離からの乖離で減点 |
| 距離延長・短縮 | 前走距離との差で「延長(+100m以上)/同/短縮」。全体・系統・種牡馬ごとの延長/短縮時の複勝率を集計し反映（例: スタミナ系の延長、スプリント系の短縮） |
| ピンポイント距離 | 種牡馬×芝ダ×距離(1800m等)の実績を、距離帯の実績から縮約して反映 |

## 8. ペース（ラップ）の分析
- **ラップ分類**: 瞬発（後半3Fが前半より1秒以上速く、ラスト2Fで11.4秒以下の加速）/ 持続（ラスト4Fの最大-最小が0.6秒以内）/ 消耗（前半3Fが後半より1秒以上速い前傾）/ 平均
- **コース別ラップ傾向**: 競馬場×芝ダ×距離ごとに各ラップ型の出現率を集計（`docs/db_summary.md`）
- **展開予想**（`racing.forecast_pace`）:
  1. 各馬のテン指数(ESI) = 近走の1〜2角の位置取り（新しい走ほど重い）。履歴がない馬は出馬表の脚質 → 父産駒の脚質分布 → 系統の事前値
  2. 逃げ候補(ESI≥0.85)・先行勢(0.62〜0.85)の頭数と比率を数える
  3. 逃げ候補3頭以上/前に行く馬が5割以上 → **ハイ(消耗)**、逃げ不在・単騎で前が少ない → **スロー(瞬発)**、それ以外 → **ミドル**（コースの最多ラップ型を採用）。1200m以下はスローにしない
- **ペース適性**: 系統・種牡馬のラップ型別成績（瞬発戦に強いディープ系、消耗戦に強いロベルト系 等を実測）＋馬自身のラップ型別の着順率

## 9. 脚質の分析
- **脚質判定**: 通過順の1角位置で 逃げ(1番手) / 先行(4番手以内 or 前3割) / 差し(〜65%) / 追込
- **コース脚質バイアス**: 競馬場×芝ダ×距離×脚質の複勝率（実績30走以上で事前値を置換）。事前値は小回り(中山・福島・小倉・札幌・函館)とダートで先行有利
- **ペース×脚質**: 消耗戦=差し・追込有利、瞬発戦=逃げ・先行有利（実測 `style_pace` で更新）
- **単騎逃げ**: 逃げ候補が1頭だけならその馬に加点
- **上がり性能**: 近走の上がり3F順位3位以内率。瞬発戦想定時に加点
- **馬場×脚質**: 良/道悪別の脚質成績、逃げた時の騎手成績も集計

## 10. その他の多角的要因（`factors.py`）
実績が十分な条件は実測値、少ない間は控えめな事前効果を使う。

| 要因 | 分析内容 | 事前の傾向（データで上書き） |
|---|---|---|
| ローテーション | 前走からの日数で 連闘/中1週/中2-4週/中5-8週/休み明け(〜6ヶ月)/長期休養明け。叩き2戦目。調教師ごとの休み明け成績 | 中2-4週が標準、長期休養明けは割引、叩き2戦目は上積み |
| 斤量 | 出走馬平均との差（距離が長いほど影響大）と前走比の増減 | 1kg重いごとに減点、斤量減は加点 |
| 馬体重 | 前走比 大幅減(-10kg〜)/減/増減なし/増/大幅増(+10kg〜)（当日発表後にカードへ入れると反映） | 大幅減・大幅増は割引 |
| クラス | 昇級/同クラス/降級（重賞は格で判定） | 昇級初戦は割引、降級は加点 |
| 騎手 | 継続騎乗/乗り替わり、乗り替わり前後の騎手力の差 | 上位騎手への乗り替わりは勝負気配 |
| 季節×性別・年齢 | 性別×季節、年齢×季節、種牡馬×季節（夏に強い血統など） | 実測のみ |
| コース実績 | 同じ競馬場×芝ダでの 初/経験/好走/勝利 | 勝利経験は加点 |
| 左右回り | その馬の右回り・左回り別の平均着順率の差 | 実測のみ |
| タイム指数 | 走破タイムを 場×芝ダ×距離×良/道悪 の基準（平均・標準偏差）で標準化（50が平均）。直近5走の最高と直近を出走馬内で相対化 | 実測のみ |
| 着差 | 近3走の勝ち馬とのタイム差（着順より正確な能力差） | 0.3秒以内は加点 |
| インブリード | 4×5以内のクロスの有無、祖先別（サンデーサイレンス、Northern Dancer 等）の実績 | 実測のみ |
| 新馬 | 父・調教師のデビュー戦成績 | 実測のみ |
| 頭数 | 少頭数/中頭数/多頭数 × 脚質 | 実測のみ |
| 妙味 | 種牡馬・騎手の単勝回収率（過剰人気/過小評価）を根拠欄に表示 | 評価値には入れない |

## 10.5 コース形態・頭数・競走内容（`factors.py`, `knowledge.course_attrs`）
- **コース形態**: 全コースを 回り（右/左/直線）・直線の長さ（長≥450m/中/短<350m、内回り/外回りを距離から判定）・坂（東京・中山・阪神・中京）・コーナー（大回り/小回り）に分類
- **馬自身の適性**: 近走のうち、今回と同じ形態のコースでの平均着順率と、それ以外との差（直線・坂・コーナーごと）
- **種牡馬の適性**: 産駒の同じ形態のコースでの複勝率を、父自身の平均と比べた差
- **頭数**: 今回と同じ頭数帯（〜10頭/11-14頭/15頭〜）での馬自身の成績、種牡馬の頭数帯別成績
- **休み明け**: その馬自身の過去の休み明け（中9週以上）での成績、種牡馬・厩舎の休み明け成績
- **通過順位と上がり**: 4角通過順位から着順への追い上げ幅、上がり3F順位（切れ）
- 学習の結果、**上がり3Fの切れは市場の評価以上に効く**一方、**4角からの大きな追い上げはむしろ過大評価されやすい**（`docs/analysis/learned_weights.md`）

## 10.6 専門家見解の取り込み（`experts.py`）
- 亀谷敬正（血統ビーム）・望田潤・水上学・坂上明大などのコラム/予想コメントから、血統に関する主張の**要点と出典のみ**を `data/knowledge/expert_notes.json` に登録（本文は転載しない）
- 各主張は実績データで『その条件で父（系統）が自身の平均より走っているか（父内z）』を検証し、**裏付けのあるものだけ**予想に小さく反映。結果は `docs/analysis/expert_check.md`
- コラム本文は GitHub Actions（`fetch-sources.yml`、毎週木曜）で取得し、非公開の作業用ブランチ `sources` に保存

## 10.7 傾向の波（`trend.py`）
- **連続好走血統**: 同名レース（同じ競馬場・芝ダ）の過去8回の3着内馬の父・父系統・母父系統・脚質・枠を年ごとに並べ、直近から何年連続で絡んでいるかを数える（主流系統は出走シェアを考慮）
- **血統の勢い**: 種牡馬・父系統の、同じ競馬場×芝ダでの直近1年の複勝率とそれ以前との差
- **今の開催の馬場傾向**: 直近14日の同じ競馬場×芝ダの、枠（内/中/外）・脚質（前/後）別の複勝率
- いずれも予想日より前のデータだけで計算。続くかどうかの検証と現在の一覧は `docs/analysis/trends.md`
- **コースバイアス**: 開催日目（開幕週/2週目/3週目/4週目以降）・馬場状態（良/稍重/重・不良）ごとの枠・脚質の有利不利を、普段（同じ競馬場×芝ダ全体）との差で評価

## 10.75 牝系（ファミリーライン, `family.py`）
- 兄弟（同じ母）・一族（同じ2代母／3代母／4代母）の、同じ条件（芝ダ・距離帯・馬場）での人気比（実際の3着内数 / 人気からの期待数）
- 本馬が初めて走る条件ほど重視（初ダート・初距離・初道悪）。検証と有力牝系の一覧は `docs/analysis/family.md`
- 3〜5代母は `data/tail_female.json`（5代血統表から補完）

## 10.76 国別タイプ（`country.py`）
- 日本型（瞬発力・直線のトップスピード）／米国型（スピードの持続・速いペース・ダート）／欧州型（スタミナ・馬力・道悪）。割り当ては `data/knowledge/country_types.json`
- 父・母父・父×母父のタイプ × 条件（芝ダ・距離帯・馬場・直線・坂・頭数・距離変化）の人気比を要素化。検証は `docs/analysis/country_types.md`

## 10.8 人気帯内の相対指標（来ない人気馬・来る人気薄, `value.cond_score`）
- 条件ごとに「同じ人気帯の平均と比べた複勝率」（縮約つき対数比）を `data/knowledge/cond_rates.json` に保存し、その馬に当てはまる条件を足し合わせる
- マイナスが大きい人気馬は「危険な人気馬」として予想に明示し、確率を割り引く。プラスが大きい人気薄は加点
- 専門家見解は、実績で裏付けのあるものは見解の向き、**逆の傾向が出たものは実績の向き**で反映

## 11. 騎手・調教師
騎手全体、騎手×競馬場×馬場種別、調教師、騎手×調教師コンビの複勝率を縮約付きで反映（コンビは出走数20回相当で縮約）。

## 12. 馬券構成（1レース10点以内）
- **◎1頭軸（本命信頼型）**: ◎勝率30%以上かつ2番手と10pt差 → 馬連流し4点＋三連複1頭軸流し6点
- **◎○2頭軸（2強型）**: 上位2頭の勝率合計42%以上 → 単勝1点＋馬連BOX3点＋三連複2頭軸6点
- **5頭BOX（混戦型）**: 三連複BOX10点
- ☆（穴）: 血統モデル評価が市場評価の1.5倍以上の10倍以上の馬を相手に追加
