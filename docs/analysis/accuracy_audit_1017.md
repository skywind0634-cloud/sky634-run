# 予想の精度の点検（2026-10-17）

## 1. バックテストの市場評価が実オッズではなかった（最大の問題）
- DB の `results.odds` は2021〜26年で約7%しか埋まっていない。勝ち馬の単勝払戻から入れた分だけ。
- そのため `docs/analysis/strategy.md` の検証は、市場の勝率を「人気順の平均勝率から作った擬似オッズ」で作っていた。
  同じ6番人気でも8倍と20倍は区別できず、「妙味（予測勝率が市場の1.3倍以上）」の判定が本番と違っていた。
- 本番は実オッズで判定する。バックテストの回収率（本線 単勝128〜140%、厳格146%/140%）は、本番と同じ物差しでは測れていなかった。
- 対策: `python -m keiba.cli backfill-odds`（sky634-run の backfill-odds.yml）で、全馬の単勝オッズを netkeiba の結果ページから埋める（約9,600レース）。埋まったら全ての買い方を実オッズで検証し直す。

## 2. モデルは市場をわずかにしか上回っていない
過去1年の勝ち馬の対数損失（小さいほど良い）:

| 期間 | モデル | 市場（擬似） |
|---|---|---|
| 前半 | 2.127 | 2.142 |
| 後半 | 2.024 | 2.033 |

- 予測/市場の比が1.3以上の馬は、市場の見込みより1.3〜1.5倍勝っている。ただし単勝回収は132% / 90%で、後半は100%を割った。

## 3. フラグ点はモデルに無い情報を持つ
勝利数の A/E（モデルの予測勝率から見込む数との比）:

| フラグ点 | 前半 | 後半 |
|---|---|---|
| −2以下 | 0.82 | 0.86 |
| +2 | 1.00 | 1.18 |
| +3以上 | 1.10 | 1.28 |

- 前半で推定した倍率を後半に当てると、対数損失はわずかに良くなった（2.0266→2.0251）。妙味馬の回収率はほぼ変わらなかった。
- フラグは2021-26年で選んでいるので、期間内の確認にとどまる。

## 4. 朝のオッズと確定オッズ
直近4日（10/10・11・12・17）を今のコードで作り直し、同じ選び方で比べた。

| 選び方 | オッズ | 頭数 | 単勝回収 | 複勝回収 |
|---|---|---|---|---|
| 本線 | 朝 | 37 | 109% | 83% |
| 本線 | 確定 | 43 | 150% | 82% |
| 厳格軸 | 朝 | 17 | 258% | 62% |
| 厳格軸 | 確定 | 18 | 244% | 58% |

- 標本は小さい。それでも、発走に近いオッズで判定し直すほうが良さそうだ。
- 当日朝と昼に、オッズを入れ直して作り直す。
