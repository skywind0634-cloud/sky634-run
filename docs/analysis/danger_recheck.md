## 結論
- **どの組み合わせでも、1〜3番人気が3着内に来ない、とは言えない。** 1番人気は最悪の条件でも半分以上が3着内に来る。悪い材料で下がるのは5〜10ポイントだけ。
- 旧基準は後半期に効いていなかった（A/E 0.96）。新基準に絞る（`keiba/digest.py` の `is_overrated`）。
- 呼び方を「危険な人気馬」から「過信禁物の人気馬」に変える。使い方は軸・1着付けにしない、まで。3連複・ワイドのヒモには残す。各馬にその人気の3着内率の目安を付ける。
- 単独で効く前走系の材料は無かった。休み明け半年以上・7歳以上・前走1番人気で負け・15頭以上はどれも A/E 0.85〜0.95 止まり。
