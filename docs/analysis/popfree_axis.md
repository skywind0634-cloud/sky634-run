# 軸を人気を問わずフラグ点だけで選ぶ（tools/popfree_axis.py, 2026-11-07）

ユーザー指摘「人気順で買い目を変えるのは本来おかしい」。各レースでフラグ点が閾値以上の最上位1頭を軸に、ワイド→1〜5番人気＋3連複 軸−1〜2番人気−1〜4番人気。実払戻、3期＝2021-23 / 2024 / 2025-26（data/cache/flag_backtest_rows.json）。

結論: 人気の条件（3番人気以下）を外しても回収率はほぼ同じで、的中率が約10ポイント上がる。軸が1〜2番人気になったときだけ見ると回収76〜83%だが、全体では打ち消し合う。紐（1〜5番人気）は「3着内に来やすい馬」という情報なので残す。
