# 人気馬を含む「当てながら儲かる」買い方の探索（2026-10-12）

ユーザーの要望: 人気馬を絡めて的中率を保ちつつ、回収率100%超の買い方。結果: **3段階の検証（発見2021-23 / 確認2024 / テスト2025-26）を通る、的中率の高い買い方は見つからなかった。**

| 探索 | 試した数 | 3期間すべて100%超 | 備考 |
|---|--:|--:|---|
| 人気の組合せ×レース条件（競馬場・距離・クラス・頭数・開催週・馬場・月） `tools/fav_struct_search.py` | 1,738 | 3 | 的中20%以上は「中京ダ 3連複 1・2番人気→3〜6番人気（4点）」104/102/115%・的中23〜26% のみ。1,738通りから3つ程度は偶然でも出る数 |
| 1・2番人気の特徴（前走着順・着差・乗替・距離・間隔・昇降級・体重・年齢・枠、2つの組合せ） `tools/fav_feature_search.py` | 5,797 | 0 | 最良でも 101/112/98% |
| モデル確率と人気の確率の比で券を選ぶ（ワイド・馬連・3連複、1〜3番人気を含む）、前半で選び後半で確認 `tools/fav_ev_search.py` | 約1,600 | 0 | 前半165%→後半68% など、前半の上位はすべて崩れた |

- 人気馬を含む買い方の基準: ワイド1-2 回収約79%・的中29%、3連複1軸2-5BOX 約76%・26%、複勝1番人気 約84%・62%。
- モデルで相手を選ぶと、人気順で選ぶより回収率が5〜10ポイント上がる（3連複モデル1位軸6点: 85%・的中26%）が、控除率（約20〜25%）を超えない。
- 2026-10-12 の実戦（7〜11R）: ◎厳格 0/3,200円、本線 240/2,200円、3連複モデル1位軸6点 1,740/6,000円、ワイド1・2番人気→モデル上位2頭 1,590/4,000円。

## 消去法とレース選び（2026-10-12 追記, tools/elim_*.py）
- 特徴は DB（第7R以降）の近走から: 近3走の着差・着順・前走上がり順位・前走位置・昇級・間隔・距離変更・芝ダ替わり・馬体重・年齢。発見2021-23/確認2024/テスト2025-26。
- 3期間とも3着内5%以下の消し条件: 「7歳以上＆近3走すべて1.0秒以上負け」2.5〜4.6%、「同じ芝ダで1.0秒未満の走りなし＆近3走すべて1.5秒以上負け」3.6〜5.0%、「前走後方＆近3走すべて1.5秒以上負け」4.3〜5.0%、「7歳以上＆近3走すべて6着以下」3.9〜4.7%。1〜6番人気で A/E が3期間とも0.6以下の消し条件は無し。
- 消し条件で8番人気以内の馬が消えるレースに絞り、残りの人気上位5頭の3連複BOX（10点）: 的中36〜39%（全レースは31〜34%）、回収率80/73/77%。的中率は上がるが回収率は上がらない（消える馬は市場も買っていない）。

## 展開（前に行く馬の数）× 脚質（tools/pace_style_db.py）
- 前走で前15%にいた馬の数から、実際のペース型はよく当たる: 4頭以上→消耗71%・瞬発2%、0〜1頭→消耗40%・瞬発18%。
- ただし展開別の脚質（前/中/後）の3着内A/Eは 0.91〜1.07 で、どの組合せも回収率は人並み（オッズに織り込み済み）。
