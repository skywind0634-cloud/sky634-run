## 1. 人気と配当

- 過去10年: 1番人気【4.0.2.4】複勝率60%、2番人気【2.3.0.5】、3番人気以内【6.4.3.17】。毎年1〜3番人気から1頭が連対。ただし3番人気以内同士のワンツーは0回。
- 勝ち馬は7番人気以内。10番人気以下は【0.1.3.85】で、3着まで。3着に穴が来た年が高配当（2017年 55万、2018年 10万、2025年 14万）。
- 3連複は1,570〜45,690円、中央値は約6,400円。「軸は上位人気、相手に1頭穴」で、万馬券が年に1回あるかどうか。
- 1番人気の倍率は過去5回で2.7〜3.9倍。今年は二冠のロブチェンが2倍を切る見込み。DB の全レースでは、1番人気1.5倍以下の3着内率は88〜91%、1.6〜2.0倍は75〜78%（`docs/analysis/odds_structure.md`）。

## 2. 前走
- 過去10年の前走別: 神戸新聞杯組【4.3.3.51】（数は最多だが率は低い）。過去5回（DB）では、セントライト記念組 A/E 1.16、神戸新聞杯組 0.54、日本海S組 2.07（4頭中2頭が3着内）。
- 近年は2勝クラス・3勝クラス（日本海S・木曽川特別・茶臼山高原特別）の勝ち馬が3着内に来る。2023年ドゥレッツァ・2024年ヘデントールは日本海S1着から。
- 記事の集計では、3着内5頭が「前走で芝2200m以上を勝利」。DB の5回でも、前走1着は A/E 1.11。

## 3. 枠・位置取り・展開
- 京都開催10年: 2枠【4-2-0-14】が最多の4勝（5番人気以内なら【4-1-0-3】）。7枠は【2-2-4-21】で好走数が最多。4・5枠は0勝。1枠【1.0.0.15】・8枠【0.0.1.23】は苦戦（過去8年の記事）。
- **人気馬は内枠**: 3番人気以内で馬番1桁は勝率31%・単勝回収115、2桁は勝率14%・回収58。
- **穴馬は外枠**: 4〜9番人気で1〜4枠は複勝率6.9%、5〜8枠は35.5%。
- DB の5回: 3着内15頭のうち7〜8枠が9頭（京都の3回では9頭中7頭）。
- 勝ち馬は5回とも最後のコーナーで4番手以内。DB の芝2600m以上でも、最後のコーナーで前20% は A/E 1.48/1.36、後方50% は 0.46/0.61。**3〜4コーナーで動ける馬（2024年3着アドマイヤテラは15-12-2-1）**。
- ラップ: 京都の3回は中盤が13秒台に緩み、後半1000mは58〜60秒の持続戦。上がり3Fは34.6〜36.3秒。瞬発力より、長く脚を使えるかが問われる。

## 6. 買い方の考え方（枠順・オッズ確定後に買い目カードを作る）
1. **軸は上位人気から1頭。** 毎年1〜3番人気が連対している。ロブチェンが2倍以下なら3着内率は75〜90%。内枠ならさらにプラス。
2. **相手**: セントライト記念組・前走で2200m以上を勝った馬・父キンカメ系（ドゥラメンテ・レイデオロ・ルーラーシップ）・母父欧州型（サドラー・デインヒル）・3〜4コーナーで動ける先行〜中団の馬。
3. **3着に穴を1頭**: 4〜9番人気なら5〜8枠（複勝率35.5%）。10番人気以下は3着まで。
4. 3番人気以内同士のワンツーは10年で0回。馬連・馬単は、上位人気から4〜9番人気へ流す。
5. 3連複は「1番人気−相手（4〜7頭）−相手」で、中央値が約6,400円のレンジを狙う。◆期待値3連複・ワイド（当日オッズ）も重ねる。
