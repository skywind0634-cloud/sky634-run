# 本線・厳格・準本線を全馬の実オッズで再検証（2026-10-17）

これまでの検証（`docs/analysis/strategy.md`）は、市場の評価を「人気順の平均勝率から作った擬似オッズ」で代用していた。
全馬の確定単勝オッズを netkeiba から補完したので、`keiba/strategy.py` の collect を実オッズで作り直した
（2025-10〜2026-09・1,555レース。数字は前半 / 後半、境目は2026-04）。

| 買い方 | 擬似オッズ | 実オッズ | 判断 |
|---|---|---|---|
| 本線（妙味馬）の単勝 | 129% / 138% | **132% / 124%**（tools/strategy_strict_combo.py の [V] では 139% / 142%） | 残す |
| 本線の複勝 | 92% / 96% | **85〜88% / 90〜93%** | **外す** |
| 本線のワイド 軸→1〜3番人気 | — | 90% / 95% | 使わない |
| 本線の馬連 軸→1〜3番人気 | — | 98% / 114% | 残す（境目） |
| 厳格軸の単勝 | 193% / 188% | 193% / 188% | 残す |
| 厳格パッケージ（単勝＋ワイド＋馬連＋3連複） | 141% / 135% | 141% / 135% | 残す |
| 準本線（7〜9番人気・走る条件満点）の単勝 | 124% / 175% | 124% / 175% | 残す |
| 準本線の複勝 | 97% / 132% | 97% / 133% | 残す（少額） |

- 厳格と準本線は、市場の評価を使わない条件（妙味条件・走る条件）で選んでいるので、数字は変わらなかった。
- 本線は市場との比で選ぶので、実オッズにすると選ばれる馬が少し変わる。単勝は100%を超えたままだが、複勝は負け越した。
