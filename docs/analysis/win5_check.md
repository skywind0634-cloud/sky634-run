# WIN5 は当てやすいか（2026-11-05, ユーザー質問「1着だけを当てるWIN5の方が当てやすい？」）

DB（第7R以降・未勝利と障害を除く）の 2021-01〜2026-10 の日曜 213日。WIN5 の対象は日曜の 10R・11R の5レースで近似した（11R を先に、残りは主場の10R）。
配当は WIN5 の実際の配当がDBに無いので、単勝オッズから出した勝率の積で推定した（推定配当 ＝ 0.7 × 100円 ÷ 5レースの1着馬の勝率の積。キャリーオーバーと、WIN5で人気馬にお金が偏る分は入っていない）。

- 1着馬の人気: 1番人気27%・2番人気22%・3番人気11%・4〜5番人気17%・6番人気以下23%。
- 各レースで人気上位k頭を買ったとき（3期＝2021-23 / 2024 / 2025-26）:

| 買い方 | 点数（金額） | 的中率 | 推定回収率 |
|---|---|---|---|
| 各2頭 | 32点（3,200円） | 4% / 5% / 0% | 153% / 279% / 0% |
| 各3頭 | 243点（24,300円） | 10% / 5% / 6% | 92% / 37% / 164% |
| 各4頭 | 1,024点（102,400円） | 18% / 5% / 14% | 59% / 9% / 61% |
| 各5頭 | 3,125点（312,500円） | 32% / 16% / 28% | 71% / 35% / 62% |
| 1番人気のオッズで2〜5頭 | 中央値405点 | 14% / 5% / 11% | 109% / 21% / 104% |

結論: 当てにくい。1レースの1着を人気上位3頭で拾える確率は約6割だが、5レース全部だと 0.6^5 ≒ 8%。的中は年に数回で、回収率は当たった回の配当しだいで期ごとに大きく振れる（再現性がない）。
今の本命枠（的中15〜60%）の代わりにはならない。買うなら、少額の遊びにとどめる。
